# jaeminlang

재민랭은 한국어와 그 외 기호로 코딩할 수 있는 ~~난해한~~ 프로그래밍 언어입니다.  
또한 난해한 프로그래밍 언어 치고는 높은 가독성과, 의외의 생산성을 제공합니다.  

## 실행

재민랭 소스코드를 실행하시려면 [릴리즈](https://github.com/Pro203S/jaeminlang/releases)로 가셔서  
자신의 OS에 맞게 실행 파일을 다운로드 하신 후  

Linux / macOS의 경우:
```sh
./jaeminlang source.jml
```

Windows의 경우:  
```
jaeminlang.exe .\source.jml
```

## 코드 작성법

### 1. 키워드

재민랭의 코드는 아래와 같이 이루어져 있습니다.  
```
[키워드][구분자][인수1][구분자][인수2]...
```

재민랭에서 사용할 수 있는 키워드는 아래와 같습니다.  

|키워드|기능|
|-----|-----|
|어이쿠|주석|
|안산|출력|
|재민|입력|
|그램|변수 선언, 대입|
|러스트|반복, 조건문|
|엘릭서|함수|
|음...|return|
|콜라|논리 연산|
|팝콘|라이브러리 import|
|샤갈|NOT 논리 연산|
|해선|프로그램 종료 (0)|
|저런|프로그램 종료 (1)|
|메가커피|코드 역할 지정|
|여친|NULL|
|,|구분자|

### 2. 구분자

키워드에 인수는 `,`로 구분합니다.  
예시: `안산,3`  

### 3. 문자열

문자열을 입력할때는 `"`로 열고 닫습니다.  

> [!NOTE]
> 문자열 안의 `,`는 구분자로 처리되지 않습니다.

예시: `안산,"1,300"`

## 키워드 사용법

### 주석 (어이쿠)

주석은 `어이쿠`로 시작하는 모든 줄이 주석이 됩니다.

코드 예시:
```
어이쿠 이게 주석
어이쿠 실행되지 않습니다.
```

### 변수 (그램)

변수는 `그램`으로 선언하고 대입할 수 있습니다.  

|파라메터|비고|
|------|------|
|변수 이름|띄어쓰기를 사용할 수 있습니다.|
|변수에 대입할 값|`여친`을 사용해도 되지만, 변수가 선언되지는 않습니다.|

> [!IMPORTANT]
> 변수명에 ,와 .는 사용할 수 없습니다.  
> 변수명에 예약어를 사용할 수 있습니다.  
> 변수가 이미 선언되었을경우, 변수의 값이 변경됩니다.  
> 변수에 대입할 값에 수식을 하나만 넣을 수 있습니다.  

코드 예시:  
```
그램,변수명,120

그램,변수명,+변수명

그램,변수명,-120
```

`그램,변수명,120`은 `변수명` 변수를 선언 한 후, 120으로 초기화합니다.  
`그램,변수명,+변수명`은 `변수명` 변수에 `변수명`의 값을 더합니다.  
`그램,변수명,-120`은 `변수명` 변수에서 120을 뺍니다.  


### 입력 (재민)

입력은 `재민`으로 처리할 수 있습니다.  

|파라메터|비고|
|------|------|
|대입할 변수 이름|변수가 선언되어있지 않아도 새로 선언합니다.|

> [!NOTE]  
> Enter가 입력될 때 변수에 입력 값을 저장합니다.  

코드 예시:  
```
그램,변수명,여친

재민,변수명
```

`재민,변수명`은 `변수명`에 입력 값을 저장합니다.  

### 출력 (안산)

출력은 `안산`으로 처리할 수 있습니다.  

|파라메터|비고|
|------|------|
|변수 이름|선택|

> [!NOTE]  
> 만약 변수가 선언되어있지 않거나, 변수의 값이 여친이라면, `여친`을 출력합니다.  
> stdout으로 출력됩니다.  

코드 예시:  
```
그램,변수명,"재민"

안산,변수명
```

`안산,변수명`은 콘솔에 `변수명`을 출력합니다.

### 반복, 조건문 (러스트)

반복은 `러스트`로 처리할 수 있습니다.

|파라메터|비고|
|------|------|
|값1|값1입니다.|
|값2|값2입니다.|
|줄 번호|이동할 줄 번호입니다.|

> [!NOTE]  
> 값1과 값2가 다르다면, 줄 번호로 이동합니다.  

코드 예시:
```
그램,변수명,0

그램,변수명,+1
러스트,변수명,5,1
```

`러스트,변수명,5,1`은 `변수명`의 값이 `5`와 같지 않다면 1번째 줄부터 다시 실행합니다.

### 함수 (엘릭서)

함수는 `엘릭서`로 선언할 수 있습니다.

|파라메터|비고|
|-|-|
|이름|함수 이름|
|파라메터|여러개가 될 수 있습니다|

> [!IMPORTANT]
> 함수의 끝은 return입니다. `음...`으로 return 할 수 있습니다.  

코드 예시:
```
엘릭서,더하기,a,b
그램,result,a
그램,result,+b

음...,result

엘릭서,더하기출력,a,b
안산,더하기,a,b
음...

그램,a,10
그램,b,10

엘릭서,더하기출력,a,b
```

### return (음...)

return은 `음...`으로 사용할 수 있습니다.

> [!IMPORTANT]  
> `음...`은 단독으로 사용할 수 없고 [엘릭서](#함수-엘릭서)의 끝을 나타낼 때 사용합니다.

|파라메터|비고|
|반환할 값|여러개가 될 수 있습니다|

### 팝콘 (라이브러리 import)

`팝콘`으로 다른 jml 파일을 불러올 수 있습니다.  

jml 파일을 불러오고 그 jml 파일에 있는 **모든 함수**를 가져옵니다.  

|파라메터|비고|
|-|-|
|파일 경로|jml 파일의 경로입니다.|

코드 예시:
```
어이쿠 library.jml

엘릭서,HelloWorld
음...,"Hello World"
```

```
어이쿠 main.jml

팝콘,library.jml

안산,HelloWorld
```

### 콜라 (논리 연산)

논리 연산을 사용하려면 `콜라` 키워드를 사용해야합니다.  
사용 가능한 논리 연산에는 `&`, `|`, `=`, `<`, `>`가 있습니다. 
차례대로 AND, OR, EQUAL, LESS, GREAT입니다.  

|파라메터|비고|
|-|-|
|값|피연산자|
|연산자|논리 연산자|
|값2|피연산자|
|결과|결과를 저장할 변수 (0, 1)|

> [!NOTE]  
> AND, OR 연산자는 피연산자가 0, 1이여야 합니다.

코드 예시:
```
그램,a,0
그램,b,1
그램,r,여친

콜라,a,<,b,r

어이쿠 출력값: 1
안산,r
```

### 샤갈 (NOT)

논리 연산 중 NOT 연산을 사용하려면 `샤갈`을 사용합니다.  

|파라메터|비고|
|-|-|
|값|값 (0, 1)|
|저장할 변수|저장할 변수 (0, 1)|

코드 예시:
```
그램,a,0
샤갈,a,r

안산,r
```

### 해선 (프로그램 종료 (0))

`해선` 키워드는 프로그램을 종료합니다.  

> [!NOTE]
> `해선` 키워드로 프로그램을 종료할 시 종료 코드는 `0`이 됩니다.

코드 예시:
```
해선
```

### 저런 (프로그램 종료 (1))

`저런` 키워드는 프로그램을 종료합니다.  
위 `해선` 키워드와 다른 점은 이 키워드는 종료 코드를 `1`로 설정합니다.

> [!NOTE]
> `해선` 키워드로 프로그램을 종료할 시 종료 코드는 `0`이 됩니다.

코드 예시:
```
저런
```

### 메가커피 (코드 역할 지정)

`메가커피` 키워드는 코드의 역할을 지정합니다.  

|파라메터|비고|
|-|-|
|모드|아래 테이블 참조|

현재 지원되는 역할은 다음과 같습니다.  
|역할|설명|
|-|-|
|0|기본 모드|
|1|[네트워크 모드](./docs/NETWORK.md)|
|2|[파일IO 모드](./docs/FILEIO.md)|

기본적인 사용법은 아래와 같습니다.  
아래는 `네트워크 모드`로 변경해 API에 요청을 보내는 예제입니다.  
```
메가커피,1

그램,headers,"Accept: */*\r\n"
그램,headers,+"User-Agent: jaeminlang/0.8.0"

그램,{payload},url,"https://api.sampleapis.com/coffee/hot?title=Black%20Coffee"
그램,payload.method,"get"
그램,payload.headers,headers

재민,payload,result

메가커피,0

안산,result.status
안산,"\r\n"
안산,result.body
안산,"\r\n"
안산,result.time
안산,"\r\n"
안산,result.header
```

## 배열

재민랭에서 배열을 사용할 수 있습니다.  
배열 안에 다른 배열을 넣어서 다차원 배열도 만들 수 있습니다.

### 배열 선언하기

배열은 아래 방법으로 선언할 수 있습니다.  

```
그램,[숫자배열],-1,5,2,6,1
```

### 배열의 값 가져오기

배열의 값은 아래 방법으로 가져올 수 있습니다.  

```
그램,배열값,숫자배열.1

안산,배열값
```

정수 값을 가진 숫자 변수를 배열 인덱스로 사용할 수도 있습니다.

```
그램,i,1
그램,배열값,숫자배열.i
```

### 배열의 값 수정하기

배열의 값은 아래 방법으로 수정할 수 있습니다.

```
그램,배열값.0,-1
그램,배열값.1,-1
```

### 다차원 배열

다차원 배열은 먼저 안쪽 배열을 만든 뒤, 바깥 배열에 넣어서 만들 수 있습니다.

```
그램,[배열1],1,2,3
그램,[배열2],4,5,6
그램,[여러배열],배열1,배열2
```

다차원 배열의 값은 `.`을 이어서 가져오거나 수정할 수 있습니다.

```
안산,행렬.1.2

그램,행렬.0.1,99
안산,행렬.0.1
```

## 딕셔너리

딕셔너리는 `{}`로 이름을 감싸고 `키,값`을 짝으로 나열해 선언합니다.

```
그램,{person},name,"재민",age,20
```

빈 딕셔너리도 선언할 수 있습니다.

```
그램,{person}
```

딕셔너리의 값은 `.`을 사용해 가져오거나 추가, 수정할 수 있습니다.

```
안산,person.name

그램,person.age,21
그램,person.city,"안산"
```

배열과 딕셔너리를 서로 담아 중첩하고, `.`을 이어서 접근할 수 있습니다.

```
그램,[scores],90,100
그램,person.scores,scores

안산,person.scores.1
```
