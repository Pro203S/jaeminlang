# 재민랭 파일IO 모드

여기서는 재민랭에서 `메가커피`로 파일의 역할을 파일IO 모드로 지정하였을 때 사용되는 구문을 설명합니다.  

> [!NOTE]
> 문법은 [재민랭의 기본 문법](../README.md#문법)을 따릅니다.  
> 또한 여기에 명시되지 않은 키워드는 [재민랭의 기본 키워드](../README.md#코드-작성법)를 따릅니다.

파일IO 모드의 키워드는 아래와 같이 바뀝니다.  

|키워드|기능|
|-----|-----|
|안산|파일 존재 확인|
|재민|파일 읽기|
|러스트|파일에 쓰기|
|콜라|폴더 읽기|
|팝콘|파일 정보 가져오기|
|샤갈||
|해선||
|저런||
